# Royalty Office

**A family office for your minerals.** Subscription portal for Texas
non-operated mineral & royalty owners: their wells, their historical cashflow,
and strip-priced projections — built from the public record.

Operated as a DBA of Alamo Exploration LLC. Design doc:
`ops/royalty_office/DESIGN.md` in the internal repo.

## Status

**v0 demo build.** Fully static + demo data — deployable to Vercel with zero
backend. All owners, operators, wells and prices in this build are fictional
(generated by `scripts/generate-demo.mjs`, deterministic seed). The data layer
(`lib/data.ts`) is the seam where the production FastAPI data plane plugs in.

## Stack

- Next.js 14 (App Router) · TypeScript · Tailwind
- No chart library — hand-rolled SVG (`components/charts/`)
- No auth provider yet — demo cookie session (`/api/demo-session`); Clerk
  slots in at `app/app/layout.tsx`
- Fonts: Newsreader / Public Sans / IBM Plex Mono via `next/font` (self-hosted
  at build)

## Develop

```bash
npm install
npm run dev            # http://localhost:3000
npm run generate-demo  # regenerate data/demo.json (deterministic)
npm run build          # production build (all pages static except /api)
```

Demo walkthrough: **Claim your card** → search `Hargrove` → code `1874` →
dashboard. Or `/login` → *Enter the demo*.

## Deploy to Vercel

1. Push this repo to GitHub.
2. In Vercel: **Add New Project** → import the repo. Framework auto-detects
   Next.js; no env vars needed for the demo build.
3. Add the `royaltyoffice.com` domain in Vercel → Settings → Domains.

## Architecture notes (for the production build-out)

- `lib/types.ts` is the API contract — the FastAPI data plane returns these
  shapes; swap `lib/data.ts` internals only.
- Forecasts are precomputed server-side per page (see `app/app/cashflow/page.tsx`)
  — the client only slices horizons. Keep it that way at scale.
- Public pages (`/texas`, `/operator`, `/well`) are the SEO surface — at launch
  these generate from live data for every county/operator/well in the state.
- **Data lineage rule:** public sources only (RRC, county appraisal rolls, GLO,
  FracFocus). Nothing from license-restricted vendors crosses into this product.
- **The wall:** this product never shares user activity with any acquisition
  workflow. See `/legal/disclosures` and the design doc.
- Strip prices in production require a CME redistribution license; the demo
  ships a clearly-labeled fictional deck (`data/demo.json → deck`).
